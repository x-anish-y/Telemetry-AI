## 🌟 What is SolarBurst AI?

> *"The Sun screams in X-rays. We taught a machine to listen."*

**SolarBurst AI** is an end-to-end automated pipeline that transforms raw solar X-ray light curve data into structured, classified, and actionable scientific intelligence. It doesn't just find peaks — **it models the full burst lifecycle** from rise to decay, extracting every scientifically meaningful parameter along the way.

```
   Raw X-Ray Data ──▶ Preprocessing ──▶ Baseline Estimation ──▶ Burst Detection
        │                                                              │
        │                                                              ▼
        │                                                     Boundary Identification
        │                                                              │
        │                                                              ▼
        │                                                     Parameter Extraction

        │                                                              ▼
        ▼                                                     GOES Classification
   ☀️ THE SUN                                                          │
                                                                       ▼

                                                                  & Export
```

## 🧬 The Algorithm — How SolarBurst Thinks

<details>
<summary><b>🔍 Click to expand the full algorithmic breakdown</b></summary>

<br/>

### Step 1: 📥 Input Time-Series Preparation

The input data is a sequence of flux values over time:

```
Time Series = {(t₁, f₁), (t₂, f₂), ..., (tₙ, fₙ)}
```

Supported formats: **FITS**, **CSV**, **XLS**, **ASCII**, and more.

---

### Step 2: 📉 Rolling Baseline Computation

A moving average or rolling median estimates the local background flux level:

```
baseline(t) = rolling_median(flux, window_size)
```

This models the "quiet Sun" and filters out transient noise.

---

### Step 3: ⚡ Threshold-Based Burst Trigger

A burst candidate is flagged when:

```
flux(t) > baseline(t) × threshold_factor
```

The threshold adapts to local conditions — no hardcoded magic numbers.

---

### Step 4: 🔺 Peak Detection

Within each candidate region, the algorithm finds the **maximum flux**:

```
peak = argmax(flux[start:end])
```

This peak defines:
- 💪 Burst intensity
- 🏷️ GOES class assignment
- 📍 Event center location

---

### Step 5: 🎯 Start & End Point Detection

The algorithm traces **backward** and **forward** from the peak:

```
start ← first point where flux rises above baseline
end   ← first point where flux decays back to baseline
```

Decay conditions use half-power or return-to-baseline thresholds.

---

### Step 6: 📊 Feature Calculation

From the identified boundaries:

```python
rise_time  = peak_time - start_time    # How fast did the burst ignite?
decay_time = end_time - peak_time       # How slowly did it fade?
duration   = end_time - start_time      # Total event lifetime
peak_flux  = max(flux[start:end])       # Maximum observed intensity
```

---

### Step 7: 🏷️ GOES Classification

Each burst is classified by peak flux into standard solar flare categories:

| Class | Peak Flux Range (W/m²) | Severity |
|:---:|:---:|:---:|
| **A** | < 10⁻⁷ | 🟢 Minor |
| **B** | 10⁻⁷ — 10⁻⁶ | 🟡 Small |
| **C** | 10⁻⁶ — 10⁻⁵ | 🟠 Moderate |
| **M** | 10⁻⁵ — 10⁻⁴ | 🔴 Strong |
| **X** | > 10⁻⁴ | 💀 Extreme |

---

### Step 8: 🖥️ Visualization & Reporting

Results are rendered with:
- ✨ Shaded burst regions on interactive charts
- 📍 Start/peak/end markers with tooltips
- 🏷️ Class badges overlaid on events
- 📊 Tabular parameter summaries
- 📤 Exportable reports

</details>

## 🚀 Quick Start

### Prerequisites

```bash
Python 3.9+
Node.js 18+
npm 9+
```

### 1️⃣ Clone the Repo

```bash
git clone https://github.com/Ayush11042005/Solar-burst.git
cd Solar-burst
```

### 2️⃣ Backend Setup

```bash
# Create virtual environment
python -m venv .venv

# Activate it
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
```

### 4️⃣ Launch 🚀

```bash
# Terminal 1 — Backend
cd backend
uvicorn server:app --reload --port 8000

# Terminal 2 — Frontend
cd frontend
npm run dev
```

Visit `http://localhost:5173` and **drop some solar data** 💥
